# Frozen development protocol

Frozen before packaging. Apply the original method to the fictional repair-club development packet, retain its source hashes and output. Then adapt the generic method and run the same checks. Use the shipped browser engine without extra packages or models. Check navigation, typing guard, notes, overview, export/reopen, phone overflow, no-JavaScript reading and print-visible slides with external requests blocked. Preserve every failure.

One corrective iteration is allowed for an observed development failure. Stop when all retained artifact contracts pass, or a documented dependency/access gap prevents progress. Do not tune on held-out examples. The portfolio coordinator independently runs held-out tasks. This worker does not read that set.

These are L0 artifact and explicit source-grounding checks. Same-model development writing is not a blinded cross-family L1 quality benchmark. No audience benefit, cost saving or outside-user result is measured.
